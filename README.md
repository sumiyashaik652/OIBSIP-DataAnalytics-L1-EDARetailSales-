# OIBSIP-DataAnalytics-L1-EDARetailSales-
# 🛒 Retail Sales Data Analysis (EDA)

## 📌 Project Overview
This project focuses on performing Exploratory Data Analysis (EDA) on a retail sales dataset to uncover meaningful insights, trends, and patterns in customer purchasing behavior.

---

## 🎯 Objectives
- Understand the structure of the dataset
- Clean and preprocess the data
- Analyze sales trends and patterns
- Visualize key insights using graphs

---

## 🧰 Tools & Technologies Used
- Python 🐍
- Pandas
- NumPy
- Matplotlib
- Seaborn

---

## 📊 Key Analysis Performed
- Data cleaning and handling missing values
- Sales distribution analysis
- Category-wise performance analysis
- Time-based sales trends
- Data visualization using charts and graphs

---

## 📈 Key Insights
- Identified top-performing product categories
- Observed trends in customer purchasing behavior
- Analyzed sales variations over time
- Found patterns that can help in business decision-making
